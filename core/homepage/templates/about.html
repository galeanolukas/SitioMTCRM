Manual de Uso - MultilideresCRM

Este manual describe cómo usar el sistema ERP (Inventario, Ventas, Gastos y Reportes).

Autor: tech.multilideres.com

Novedades recientes

  • Filtro por categoría en reportes de ventas: el reporte de ventas del operador ahora permite filtrar por categoría, mostrando solo las ventas que contienen productos de la categoría seleccionada.
  • Importación completa de productos desde servidor: al importar productos del servidor ahora se traen todos los campos: flete, margen, IVA, código de proveedor, descripción y código AFIP.
  • Fecha actual por defecto en gastos: el formulario de gastos muestra la fecha y hora actual por defecto al crear un nuevo registro.
  • Corrección de precios en formulario de producto: al editar un producto existente, los precios ya no se recalculan automáticamente. Solo se calculan si los campos están vacíos (producto nuevo) o si el usuario modifica un campo manualmente.
  • Configuración de catálogo externo: nuevo módulo para sincronizar productos con un catálogo web externo (SitioCatalogoMarcos), con URL y API key por empresa.
  • Módulo Fiscal AFIP: Libro IVA Digital, Cuenta Corriente de Clientes, Asientos Contables y Facturas de Proveedores, accesibles desde Reportes (solo superusuario).
  • Transferencias internas: módulo para transferir productos entre sucursales/empresas, con búsqueda de productos y confirmación de recepción.
  • Planes de cuotas: gestión de planes de cuotas para tarjetas de crédito, con importación y exportación.
  • Remitos: gestión de remitos de entrada de mercadería desde proveedores.
  • Listas de precios: creación y gestión de listas de precios alternativas.
  • Etiquetas QR: generación de etiquetas con código QR para productos.
  • Escáner móvil: página dedicada para escanear códigos de barras desde el celular.
  • Registro de actividad: historial de acciones de usuarios en el sistema.
  • Sincronización de usuarios y permisos de operadores: el POS local replica automáticamente los usuarios y el grupo operadores desde el servidor.
  • Inventario por planilla con código como clave: importación de productos desde CSV/Excel usando el campo code como identificador único.
  • Sync periódica en POS locales: los nodos POS pueden ejecutar sincronizaciones en segundo plano cada cierto intervalo de tiempo.

Indicaciones detalladas por sección

Seguí estos pasos en cada apartado del índice para usar correctamente el sistema.

1) Ingreso y navegación
  1. Ir a /login/ y autenticarte.
  2. Desde el Dashboard, revisá KPIs y gráficos para un panorama general.
  3. Usá el menú lateral para entrar a cada módulo.
2) Empresas y cambio de empresa
  1. Abrí el menú de Empresas en el header (solo superusuario).
  2. Seleccioná una empresa para fijarla como activa o la opción “Todas”.
  3. Confirmá que los listados y POS reflejen la empresa activa.
3) Usuarios ERP
  1. Header → Empresas → Usuarios (ERP).
  2. Activar/Desactivar: botón por fila; no podés desactivarte a vos mismo.
  3. Eliminar: botón por fila con confirmación; no podés eliminar tu propio usuario.
4) Permisos del grupo Operadores
  1. Header → Permisos Operadores (solo superusuario).
  2. Marcá/desmarcá permisos necesarios para el grupo.
  3. Usá “Marcar todo / Desmarcar todo” para cambios masivos y guardá.
5) Productos e Inventario
  1. ERP → Productos: crear/editar con categoría, precio, unidad, stock, código y proveedor (opcional).
  2. Campos de precio: costo, flete (%), margen (%), PVP (sin IVA), IVA (%), precio final (con IVA).
  3. Al editar un producto existente, los precios no se recalculan automáticamente. Solo se calculan si están vacíos o si modificás un campo manualmente.
  4. Importar inventario desde la opción “Importar inventario” si aplica.
  5. Verificá el stock; se descuenta automáticamente al vender.
5 bis) Importar productos del servidor
  1. ERP → Importar inventario → pestaña “Importar del Servidor”.
  2. Seleccioná los productos a importar desde el servidor remoto.
  3. Se importan todos los campos: nombre, código, precios, flete, margen, IVA, stock, categoría, proveedor, código de proveedor, descripción y código AFIP.
5 ter) Etiquetas QR
  1. ERP → Inventario → Etiquetas QR (solo superusuario).
  2. Generá etiquetas con código QR para productos.
  3. Seleccioná productos y generá un PDF imprimible.
5 quater) Listas de Precios
  1. ERP → Inventario → Listas de Precios.
  2. Creá listas de precios alternativas con porcentajes de ajuste sobre el PVP.
  3. Asociá productos a una lista para aplicar el precio ajustado.
6) Proveedores y Remitos
  1. ERP → Proveedores: alta, edición y baja.
  2. Vinculá productos a proveedores si necesitás seguimiento.
  3. ERP → Proveedores → Remitos: registrar remitos de entrada de mercadería.
7) Clientes
  1. ERP → Clientes: administrar datos de clientes.
  2. Asociá el cliente en la venta cuando corresponda.
8) POS / Ventas
  1. ERP → POS: buscá productos por código/nombre y agregalos.
  2. Ajustá cantidades y verificá Subtotal, IVA y Total.
  3. Registrar venta: guarda sin factura.
  4. Facturar: emite factura con numeración correlativa por punto de venta y tipo.
  5. Revisá el historial de ventas recientes y abrí PDF si corresponde.
8 bis) Transferencias internas
  1. ERP → Ventas → Transferencias.
  2. Creá una transferencia de productos entre empresas/sucursales.
  3. Buscá productos por código o nombre y agregalos con cantidad.
  4. La sucursal destino puede confirmar la recepción.
8 ter) Planes de Cuotas
  1. ERP → Ventas → Planes de Cuotas.
  2. Gestioná planes de cuotas para tarjetas de crédito.
  3. Importá/exportá planes desde/hacia archivos.
8 quater) Caja diaria / Cierre de cajas
  1. Menú lateral → Caja.
  2. Abrir caja: indicá saldo inicial para el día y usuario.
  3. Durante el día, las ventas y movimientos se acumulan en la caja abierta.
  4. Desde el detalle de la caja, ingresá el saldo contado y cerrá la caja.
  5. Revisá diferencia entre saldo esperado y contado y notas de cierre.
9) Gastos / Compras
  1. ERP → Gastos: lista, crear, editar o borrar registros.
  2. La fecha y hora se cargan por defecto con la actual.
  3. Campos: fecha, proveedor (opcional), descripción, importe, pagado por, comprobante PDF/imagen (opcional).
  4. Usá el link del comprobante para visualizar/descargar.
10) Reportes de Ventas
  1. Menú lateral → Reportes → Reporte de Ventas.
  2. Filtros: tipo de reporte (diario, semanal, mensual, personalizado), formato (método de pago, ranking de productos, detalle fiscal), fechas, categoría y empresa.
  3. Filtro por categoría: muestra solo ventas con productos de la categoría seleccionada.
  4. Exportá en CSV, Excel o PDF.
10 bis) Módulo Fiscal (AFIP)
  1. Menú lateral → Reportes → Libro IVA Digital, Cta. Corriente Clientes, Asientos Contables, Facturas Proveedores (solo superusuario).
  2. Configuración AFIP desde Administración → Módulo Fiscal.
10 ter) Catálogo externo
  1. Administración → Catálogo.
  2. Configurá la URL y API key del catálogo web externo por empresa.
  3. Sincronizá productos desde el CRM hacia el catálogo.
11) Configuración de IVA
  1. Header → Configurar IVA.
  2. Ingresá la tasa como proporción (0–1). Ej.: 0.21 = 21%.
  3. Se guarda en el navegador (localStorage) y actualiza POS/formulario de venta.
12) Sincronización automática
  1. Administración → Sync automática (solo superusuario).
  2. Configurá el intervalo de sincronización con el servidor remoto.
  3. Los POS locales sincronizan productos, ventas, stock, clientes, gastos y datos fiscales.
13) Escáner móvil
  1. Menú lateral → Escáner Móvil (abre en nueva pestaña).
  2. Permite escanear códigos de barras desde el celular.
  3. Accesible para usuarios con grupo scanner o superusuarios.
14) Registro de actividad
  1. Administración → Registro de Actividad (solo superusuario).
  2. Historial de acciones de usuarios: creación, edición, eliminación de registros.

1. Ingreso y navegación

  • Accedé a /login/ con tu usuario y contraseña.
  • Tras ingresar, verás el Dashboard con KPIs y gráficos.
  • El menú lateral permite acceder a módulos: Productos, Clientes, Ventas (POS), Proveedores, Gastos, etc.

2. Empresas y cambio de empresa

  • Como superusuario, abrí el menú de Empresas en el header.
  • Elegí una empresa para fijarla como activa o seleccioná “Todas”.
  • El filtro de empresa impacta listados, POS y reportes.

3. Usuarios ERP

  • Acceso desde: Header → Empresas → Usuarios (ERP).
  • Verás un listado con: usuario, nombre, email, empresa, si es superuser y si está activo.
  • Acciones por fila:
    • Activar/Desactivar: cambia el estado del usuario.
    • Eliminar: borra al usuario (no podés eliminarte a vos mismo).

4. Permisos del grupo Operadores

  • Acceso desde: Header → Permisos Operadores (solo superusuario).
  • Marcá/desmarcá permisos del grupo operadores usando la interfaz.
  • Botones “Marcar todo / Desmarcar todo” facilitan cambios masivos.

5. Productos e Inventario

  • Gestión de productos con categoría, precio neto (sin IVA), IVA por producto, precio final (con IVA), unidad, stock, código y proveedor opcional.
  • Campos de precio: costo, flete (%), margen (%), PVP (sin IVA), IVA (%), precio final (con IVA). Al editar un producto existente los precios no se recalculan automáticamente.
  • Importación de inventario y control de stock en ventas.
  • Importar inventario (CSV/XLSX)
    • Formato recomendado de columnas:
      • name: nombre del producto (obligatorio).
      • code: código interno o de barra (opcional).
      • cat o category: nombre de la categoría (opcional). Si no existe, se puede dejar en blanco o la categoría se dejará sin asignar.
      • company (opcional): nombre de la empresa. Si existe en el sistema se asocia; si no, se deja en blanco o se usa la empresa activa.
      • pvp: precio neto sin IVA (obligatorio).
      • iva_rate: tasa de IVA en proporción (ej.: 0.21 para 21%). Si se omite, se usará el valor por defecto.
      • pvp_final (opcional): precio final con IVA. Si no se indica, el sistema lo calcula como pvp * (1 + iva_rate).
      • unit: unidad (Unidad, Kg, Mt, Lt, Caja, etc.).
      • stock: stock inicial.
      • supplier (opcional): nombre del proveedor, si aplica.
    • Las columnas categoría y empresa son opcionales: si no coinciden con registros existentes pueden quedar en blanco o se usa la configuración por defecto.
    • Las planillas pueden ser CSV (delimitado por comas) o XLSX; respetá los nombres de columnas para que la importación funcione correctamente.

5 bis. Importar productos del servidor

  • Acceso: ERP → Inventario → Importar inventario → pestaña “Importar del Servidor”.
  • Seleccioná los productos a importar desde el servidor remoto.
  • Se importan todos los campos: nombre, código, precios (PVP, PVP final, costo), flete (%), margen (%), IVA, stock, categoría, proveedor, código de proveedor, descripción y código AFIP.
  • Los productos importados quedan marcados como sincronizados para no volver a subirse al servidor.

5 ter. Etiquetas QR

  • Acceso: ERP → Inventario → Etiquetas QR (solo superusuario).
  • Generá etiquetas con código QR para productos individuales o masivamente.
  • Seleccioná productos y generá un PDF imprimible con las etiquetas.

5 quater. Listas de Precios

  • Acceso: ERP → Inventario → Listas de Precios.
  • Creá listas de precios alternativas con porcentajes de ajuste sobre el PVP.
  • Asociá productos a una lista para aplicar el precio ajustado en ventas.

6. Proveedores y Remitos

  • ABM de proveedores. Campo empresa se asigna según el contexto.
  • Productos pueden vincularse a un proveedor (opcional).
  • Remitos: ERP → Proveedores → Remitos. Registrar remitos de entrada de mercadería desde proveedores.

7. Clientes

  • ABM de clientes. Los clientes se usan en ventas y facturación.

8. POS / Ventas

  • Acceso: ERP → POS. Buscá por código o nombre, agregá ítems y ajustá cantidades.
  • El sistema calcula Subtotal, IVA y Total automáticamente.
  • Acciones:
    • Registrar Venta: guarda la venta.
    • Facturar: genera factura con numeración correlativa por punto de venta y tipo.
  • Debajo del POS se muestra un historial de ventas recientes con enlaces a PDF de factura.

8 bis. Transferencias internas

  • Acceso: ERP → Ventas → Transferencias.
  • Creá una transferencia de productos entre empresas/sucursales.
  • Buscá productos por código o nombre y agregalos con cantidad.
  • La sucursal destino puede confirmar la recepción de la transferencia.
  • El stock se ajusta automáticamente al confirmar la recepción.

8 ter. Planes de Cuotas

  • Acceso: ERP → Ventas → Planes de Cuotas.
  • Gestioná planes de cuotas para tarjetas de crédito.
  • Importá/exportá planes desde/hacia archivos CSV.

9. Compra rápida (QR + Mercado Pago)

  • Funcionalidad pensada para compras rápidas escaneando códigos QR de productos.
  • Flujo del cliente:
    • Escanea el QR de un producto desde el celular: se abre la página pública de Compra rápida para ese producto.
    • Presiona Agregar al carrito para ir armando su carrito rápido.
    • En la pantalla de carrito rápido ve el listado de productos, cantidades y total.
    • Si la empresa tiene configurado Mercado Pago, puede usar el botón Pagar ahora con Mercado Pago para completar el pago online.
  • Configuración:
    • El superusuario debe cargar las credenciales de Mercado Pago por empresa en Configuración de la empresa → Mercado Pago.
    • Solo con credenciales habilitadas la opción de pago estará disponible en el carrito rápido.
  • Validación en caja (POS):
    • Luego de que el cliente paga, se genera una Orden rápida con un preference_id de Mercado Pago.
    • En el POS, el operador puede ir al panel derecho y usar el campo Compra rápida (preference_id / ID).
    • Pegando el preference_id (o ingresando el ID de la orden rápida) y presionando Importar, el sistema crea la venta en el POS con los productos y descuenta stock.

10. Gastos / Compras

  • Módulo de Gastos: lista, crear, editar y eliminar gastos.
  • La fecha y hora actual se cargan por defecto al crear un nuevo gasto.
  • Campos: fecha, proveedor (opcional), descripción, importe, pagado por, y comprobante (PDF/imagen) opcional.
  • Los comprobantes quedan accesibles desde la lista.

11. Reportes de Ventas

  • Acceso: Menú lateral → Reportes → Reporte de Ventas.
  • Filtros disponibles:
    • Tipo de reporte: diario, últimos 7 días, últimos 30 días, personalizado.
    • Formato: por método de pago, ranking de productos, detalle fiscal (IVA/AFIP).
    • Fecha desde/hasta: rango de fechas personalizado.
    • Categoría: filtra solo ventas con productos de la categoría seleccionada.
    • Empresa: solo superusuario puede ver todas las empresas.
  • Exportación en CSV, Excel y PDF.

12. Módulo Fiscal (AFIP)

  • Acceso: Menú lateral → Reportes (solo superusuario).
  • Libro IVA Digital: registro de compras y ventas con detalle de IVA.
  • Cuenta Corriente de Clientes: estado de cuenta por cliente.
  • Asientos Contables: asientos generados desde facturación.
  • Facturas de Proveedores: registro de facturas de compra.
  • Configuración AFIP desde Administración → Módulo Fiscal.

13. Catálogo externo

  • Acceso: Administración → Catálogo (solo superusuario).
  • Configurá la URL y API key del catálogo web externo (SitioCatalogoMarcos) por empresa.
  • Sincronizá productos desde el CRM hacia el catálogo externo.
  • Se puede configurar sincronización automática con intervalo personalizado.

14. Configuración de IVA

  • Acceso: Header → Configurar IVA (modal).
  • Ingresá la tasa como proporción (ej.: 0.21 = 21%). Se guarda en el navegador (localStorage).
  • Impacta en POS y formularios de venta al recalcular los totales.

15. Sincronización automática

  • Acceso: Administración → Sync automática (solo superusuario).
  • Configurá el intervalo de sincronización con el servidor remoto.
  • Los POS locales sincronizan: productos, ventas, stock, clientes, proveedores, gastos, categorías, cierres de caja, listas de precios y datos fiscales.
  • La sincronización corre en segundo plano cada 5 minutos por defecto.

16. Escáner móvil

  • Acceso: Menú lateral → Escáner Móvil (abre en nueva pestaña).
  • Permite escanear códigos de barras desde el celular.
  • Accesible para usuarios con grupo scanner o superusuarios.

17. Registro de actividad

  • Acceso: Administración → Registro de Actividad (solo superusuario).
  • Historial de acciones de usuarios: creación, edición, eliminación de registros.
  • Permite filtrar por usuario, acción y fecha.

18. Caja diaria / Cierre de cajas

  • Objetivo: registrar la apertura de caja, movimientos de efectivo y otros medios de pago, y el cierre diario por usuario y empresa.
  • Permisos clave:
    • erp.view_cash_register: ver listado y detalle de cajas.
    • erp.add_cashregister: abrir nuevas cajas.
    • erp.close_cash_register: cerrar cajas abiertas.
    • erp.add_cashmovement: registrar ingresos/egresos manuales.
    • erp.delete_cashregister: eliminar cajas (solo roles autorizados).
  • Apertura de caja:
    • Ir a ERP → Caja y usar el botón de Nueva caja.
    • Seleccionar empresa (si aplica) e indicar el saldo inicial.
    • La caja queda en estado abierta y se asocia al usuario actual.
  • Movimientos de caja:
    • Desde el detalle de la caja abierta, agregar Movimientos (ingresos/egresos).
    • Campos: tipo (Ingreso/Egreso), monto, tipo de pago (efectivo, tarjeta, transferencia, otro) y descripción.
    • Estos movimientos afectan el cálculo del saldo esperado.
  • Cálculo de totales:
    • La lista y el detalle muestran totales dinámicos para cajas abiertas: ventas por tipo de pago, gastos y saldo esperado.
    • Para cajas cerradas se muestran los valores guardados al momento del cierre.
  • Cierre de caja:
    • En el detalle de la caja, ingresar el saldo final contado.
    • El sistema calcula la diferencia entre saldo esperado y saldo contado.
    • Al confirmar, la caja pasa a estado cerrada y ya no admite nuevos movimientos.
  • Sincronización con servidor:
    • Los cierres de caja y movimientos se pueden sincronizar con la BD remota mediante los comandos de sync.
    • Los campos de sincronización permiten identificar qué cajas ya fueron subidas y evitar duplicados.
Sugerencias
  • Mantené tus usuarios de operadores con permisos mínimos necesarios.
  • Usá Reportes para descargar información con fecha en el nombre del archivo.
  • Respalda periódicamente base de datos y archivos de comprobantes.
