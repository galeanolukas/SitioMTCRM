Alternativa avanzada (Git/pip manual)

Si preferís actualizar manualmente desde consola usando Git y Python, el flujo típico es:

  • Abrir una consola en la carpeta del proyecto.
  • Activar el entorno virtual: call venv\\Scripts\\activate.
  • Actualizar código: git pull.
  • Actualizar dependencias: python -m pip install -r requirements.txt.
  • Aplicar migraciones: python manage.py migrate.

Nota: este módulo informa la disponibilidad de actualizaciones y proporciona métodos automáticos y manuales para mantener el sistema actualizado.
