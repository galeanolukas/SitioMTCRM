Cómo actualizar este POS
  1. Cerrar todas las ventanas del POS (navegador y servidor local si aplica).
  2. En esta PC, ir a la carpeta del proyecto (donde estén lanzar_pos.bat y actualizar_pos.bat).
  3. Ejecutar actualizar_pos.bat y seguir los mensajes en pantalla.
  4. Cuando finalice, volver a iniciar el POS con lanzar_pos.bat y entrar de nuevo al sistema.

Alternativa avanzada (Git/pip manual)

Si preferís actualizar manualmente desde consola usando Git y Python, el flujo típico es:

  • Abrir una consola en la carpeta del proyecto.
  • Activar el entorno virtual: call venv\\Scripts\\activate.
  • Actualizar código: git pull.
  • Actualizar dependencias: python -m pip install -r requirements.txt.
  • Aplicar migraciones: python manage.py migrate.

Nota: este módulo solo informa la disponibilidad de una nueva versión y documenta el procedimiento recomendado de actualización. La ejecución de scripts o comandos sigue siendo manual para mantener el control en cada local.
