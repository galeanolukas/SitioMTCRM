Cómo actualizar este POS
  1. Cerrar todas las ventanas del POS (navegador y servidor local si aplica).
  2. En esta PC, ejecutar tu instalador/actualizador (por ejemplo instalador_pos_bat.bat) o el procedimiento que uses para desplegar la nueva versión.
  3. Si usás Git directamente en este equipo, los pasos típicos son:
    • Abrir una consola en la carpeta del proyecto.
    • Actualizar código: git pull.
    • Actualizar dependencias: pip install -r requirements.txt.
    • Aplicar migraciones: python manage.py migrate.
  4. Volver a iniciar el POS (script de lanzamiento o servidor local) y entrar de nuevo al sistema.

Nota: este módulo solo informa la disponibilidad de una nueva versión. La ejecución del instalador o comandos de actualización sigue siendo manual para mantener el control en cada local.
